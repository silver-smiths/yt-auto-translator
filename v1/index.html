자막 자동 번역&등록기
for YouTube

YouTube 스튜디오 자막을 Gemini AI로 26개 언어에 자동 번역·등록.
클릭 한 번으로 전 세계 시청자에게 닿으세요.

🔗 Chrome 웹 스토어에서 설치 GitHub
주요 기능

한 번에 26개 언어, 반복 없이

크리에이터가 번역에 쓰던 시간을 콘텐츠에 돌려드립니다.

🌍
26개 언어 동시 번역
영어, 일본어, 중국어, 스페인어 등 주요 언어를 한 번의 클릭으로 처리합니다.
🤖
Gemini AI 번역 품질
Google의 최신 AI 모델(Gemini 2.5 Flash 등)로 자연스러운 번역을 제공합니다.
📤
YouTube 스튜디오 직접 등록
번역 결과를 자동으로 자막 트랙에 업로드합니다. 별도 작업이 필요 없습니다.
💡
중복 번역 자동 건너뜀
이미 번역된 언어는 감지해서 건너뛰어 API 토큰을 아낍니다.
📊
실시간 진행률
언어별·청크별 번역 진행 상황을 세밀하게 확인할 수 있습니다.
🔑
간편한 시작
Gemini API 키 입력 후 즉시 사용 가능. 무료 티어로도 충분합니다.
사용 방법

5분이면 준비 완료

복잡한 설정 없이 바로 시작할 수 있습니다.

1
Gemini API 키 발급
Google AI Studio에서 무료로 API 키를 발급받습니다.
2
확장 프로그램 설치 & 설정
Chrome 웹 스토어에서 설치 후, 설정 페이지에 API 키를 입력합니다.
3
YouTube 스튜디오로 이동
자막을 등록할 영상의 수정 페이지를 엽니다.
4
언어 선택 후 번역 시작
화면 오른쪽 사이드바에서 번역할 언어를 선택하고 [번역 시작]을 클릭합니다.
5
자동 등록 완료
번역이 완료되면 선택한 언어의 자막이 자동으로 YouTube에 등록됩니다.
참고 사항

알아두세요

  • Gemini API 사용에 따른 비용은 Google의 요금 정책을 따릅니다. 무료 티어가 제공됩니다.
  • API 키는 사용자의 브라우저에만 저장되며 외부 서버로 전송되지 않습니다.
  • 자막이 없는 영상에는 사용할 수 없습니다. 먼저 원본 자막을 등록해 주세요.
  • AI 번역이므로 오역이 있을 수 있습니다. 업로드 후 반드시 검토해 주세요.
