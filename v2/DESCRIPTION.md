# YTAT v2 — 서비스 설명

## 한 줄 요약
YouTube Studio 자막 자동 번역·등록 Chrome 확장 프로그램의 **유/무료 혼합 서비스** 버전

---

## 배경 및 목적

v1은 사용자가 직접 Gemini API 키를 발급·관리해야 하는 **무료 전용** 버전이다.
진입 장벽(API 키 발급 절차)이 높고, 번역 속도도 무료 티어 한계(5초 간격, 1언어씩)에 묶인다.

v2는 **크레딧 결제 시스템**을 도입해 두 가지 방식을 함께 제공한다:
- **API 키 모드 (무료)**: v1과 동일. 사용자 본인 키 사용, 느리고 1언어씩 처리
- **크레딧 모드 (유료)**: 결제한 크레딧으로 번역. 빠르고 3개 언어 동시 처리

---

## 핵심 기능

### 공통
- YouTube Studio 영상 편집 페이지 사이드바로 UI 변경 (v1 팝업 방식 → 사이드바)
- 26개 언어 지원
- 이미 번역된 언어 자동 스킵
- 온보딩 카드 (최초 설치 시 안내)

### API 키 모드 (무료)
- 사용자 Gemini API 키 직접 입력
- 청크 단위 번역 (자막 50줄씩 분할)
- 1개 언어씩 순차 처리
- 속도: ~5초 간격 (무료 티어 RPM 준수)

### 크레딧 모드 (유료)
- 결제한 크레딧으로 번역 (API 키 불필요)
- 전체 자막 한 번에 처리 (청크 분할 없음)
- 3개 언어 동시(병렬) 처리
- 속도: 빠름 (서버 측 Gemini API, 유료 RPM)
- 잔여 크레딧 표시 (원화/달러가 아닌 크레딧 수량)

## 크레딧 정책

| 항목 | 내용 |
|------|------|
| 환율 | 1 USD = 1,400 KRW (고정, 변동 시 조정) |
| 1 크레딧 | = $1 USD = ₩1,400 |
| 표시 | 크레딧 수량 (예: 12.42 크레딧) |
| 결제 수단 | 카드 결제 (Portone) / 계좌이체 |
| 결제 페이지 | silver-smiths.com/project/ytat-credits.html |
| 유효기간 | 결제일로부터 1년 |
| 환불 | 결제 후 7일 이내 미사용 크레딧 전액 환불 |

### 크레딧 소모 방식
- 실제 Gemini API 비용 기반 차감
- 티어별 배율 적용 (서비스 마진):
  - light (누적 $0~$30): ×1.3
  - standard (누적 $30~$100): ×1.2
  - heavy (누적 $100+): ×1.1

## 관련 외부 시스템

| 시스템 | 역할 |
|--------|------|
| Supabase | 사용자·크레딧·결제·번역 이력 DB |
| Cloudflare Workers | API 서버 (크레딧 조회, Gemini 프록시, 결제 웹훅) |
| Portone | 결제 처리 (Toss / Stripe 통합) |
| silver-smiths.com | 결제·소개 페이지 호스팅 |
| Telegram Bot | 에러 알림 |
